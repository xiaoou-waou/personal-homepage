# 个人网站二

小欧的独立复刻版本。视觉参考：https://dayuai.online/ 。所有新文件都在 `个人网站二复刻` 内，父目录原网站没有修改、覆盖或重新部署。

## 打开

双击 `启动个人网站二.command`，或在本文件夹运行：

```bash
npm start
```

打开 http://127.0.0.1:4178 。预览服务仅监听本机；关闭终端或按 Ctrl+C 停止。也可以把整个文件夹放到支持静态文件的服务器中，资源路径支持子目录。不要用 `file://` 双击 HTML 预览动态效果，浏览器会限制 JavaScript 模块。

## 改内容

编辑 `content.js`；版块映射与文字在 `tools/build.mjs`。然后：

```bash
npm install
npm run build
npm run check
```

`build` 只生成本文件夹内的 `index.html`、合并样式及项目文字封面；不会读写父目录原页面。`check` 会只读检查四个原文件的 SHA256、所有项目与文章链接、本地资源、ID/标签和脚本语法。
